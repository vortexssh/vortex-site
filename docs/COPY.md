# Copy truth — что можно обещать на лендинге

Правки смысла: `src/copy.ts` (RU и EN **вместе**). Не пиши фичи, которых нет в `docs/ECOSYSTEM.md`.

## Голос

Прямой, технический, без «AI-powered» и без корпоративного SaaS. Как Tailscale, не как конструктор сайтов. Короткие предложения. Боль — флот за NAT, ключи на ноутбуках, продления в почте.

## Можно утверждать

- WebSSH / PTY в браузере через агент, хост без белого IP.
- TCP/SSH proxy для GUI/TUI, включается per-host.
- Телеметрия CPU/RAM/net/uptime, live, Redis TTL.
- 2FA (TOTP) обязателен на терминал, прокси, телеметрию, задачи, выпуск агента.
- В облаке нет паролей и private key целевых серверов.
- Агент — исходящий WSS, порты не открывает.
- Биллинг: календарь, плательщики, валюты, FX, напоминания, Renew.
- Плагины отдельными демонами, UI-слоты в кабинете.
- Публичная статус-страница `/u/{slug}` без IP и без входа в кабинет; hidden-хосты скрыты.
- Cron-задачи исполняются на агенте.
- Клиенты: Web, TUI, GUI; API keys `vxk_`.

## Нельзя утверждать

- Хранение SSH-ключей/паролей (даже «зашифрованных») в Vortex Cloud.
- Работа острого контура без 2FA.
- Что агент слушает 22/443 с интернета.
- Исторический склад метрик в Postgres / «forever graphs».
- Что лендинг *и есть* кабинет.
- Конкретные SLA, цены, open-source лицензию — пока не зафиксированы в этом репо.
